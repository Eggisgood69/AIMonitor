# 1.28 吋 LCD 版外殼（SolidWorks，設計中）

給 ESP32-2424S012N 用的外殼。資料夾結構與命名規則見上一層 [README](../README.md)。

## 要量的尺寸

網路上的模型跟實物不一樣（`reference/` 那份是觸控版，螢幕前面多一層觸控玻璃），請用游標卡尺量自己的板子：

| 項目 | 備註 |
|---|---|
| PCB 外形與厚度 | 圓板或有切平的邊 |
| 螢幕玻璃直徑、可視區直徑 | 可視區約 Φ32.4（1.28 吋） |
| 玻璃表面到 PCB 正面的高度 | 決定前框深度 |
| PCB 背面最高零件高度 | USB-C 座、晶片、4-pin 排座 |
| USB-C 位置與插頭外殼尺寸 | 插頭外殼約 12.5 × 7 mm，長度含護套約 20-25 mm |
| BOOT / RST 鍵位置與高度 | BOOT 是操作按鈕（短按翻頁、長按標為已讀），外殼要能按得到 |
| 背面 4-pin 排座位置 | 選配 WS2812 LED 的線從這裡接出來（RX = GPIO20） |
